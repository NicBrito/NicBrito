## Nicolas Brito

**AI Developer & Prompt Engineer** at V-Lab UFPE · Computer Engineering at CIn UFPE · Recife, Brazil

I build applications on top of language models. At V-Lab UFPE — the innovation lab of UFPE's Center for Informatics (CIn) — I work on automated educational content generation for AVAMEC, the Brazilian Ministry of Education's virtual learning environment: integrating OpenAI, Anthropic and Google Gemini APIs into production applications, versioned prompt engineering evaluated against metrics, and Specification-Driven Development.

I was an electronics technician before I was a developer, which is where the interest in computer architecture, digital systems and low-level programming comes from.
